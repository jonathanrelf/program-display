# Visual asset provenance

`program-display-logo.png` is the project mark used in the repository README
and intended for the OBS Community resource icon.

- Created: 2026-09-21
- Tool: OpenAI built-in image generation
- Direction and selection: Jonathan Relf with OpenAI Codex assistance
- Format: 512 x 512 RGBA PNG with a transparent background
- Third-party marks: none; the brief explicitly excluded OBS, Apple and Elgato
  branding

Final generation brief:

> Refine the Program Display icon into a restrained, premium developer-tool
> mark. Keep only the core idea: one selected physical display and one
> intentional incoming route. Use flat geometric construction, a near-black
> display outline, one cyan program frame, a cyan route terminating precisely
> at it, and a small amber confirmation point. Keep it legible at 48–64 px on a
> transparent background. Use no text, play symbol, watermark or third-party
> branding.

The repository's development disclosure documents the use of generative tools.

`program-display-dock.png` is an unedited maintainer-supplied screenshot of the
v0.1 release candidate running in OBS Studio on 2026-09-21. It shows the compact
docked state after the saved Elgato Program destination was restored
automatically.
